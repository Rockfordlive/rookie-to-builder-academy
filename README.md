# Rookie-to-Builder Academy

This is a static learning web app. It can be hosted on GitHub Pages because it only needs browser files:

- `index.html`
- `styles.css`
- `app.js`
- `claude-foundations-content.js`
- `.nojekyll`

## Important Safety Note

This course includes company-specific learning content. Use an approved internal/private repository if the content should not be public. Do not publish PDFs, decks, API keys, credentials, or customer/company data.

## Publish To GitHub Pages

1. Create a new GitHub repository.
2. Add only the static app files listed above.
3. Push the files to the `main` branch.
4. In GitHub, open the repository.
5. Go to `Settings` > `Pages`.
6. Under `Build and deployment`, choose `Deploy from a branch`.
7. Choose branch `main` and folder `/ (root)`.
8. Click `Save`.
9. Wait a few minutes, then use the `Visit site` link on the Pages settings page.

The project URL usually looks like:

```text
https://<your-github-username-or-org>.github.io/<repository-name>/
```

## Updating The Site

After the first publish, edit the files locally, commit the changes, and push to GitHub again. GitHub Pages will redeploy automatically.
